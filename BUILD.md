# Build Instructions

## System Requirements

### Arch Linux
```bash
sudo pacman -S \
    gcc \
    gtk4 \
    gtk4-layer-shell \
    json-c \
    pkgconf \
    make
```

### Ubuntu/Debian (Untested)
```bash
sudo apt-get install \
    build-essential \
    libgtk-4-dev \
    libgtk4-layer-shell0 \
    libjson-c-dev \
    pkg-config
```

### Fedora (Untested)
```bash
sudo dnf install \
    gcc \
    gtk4-devel \
    gtk4-layer-shell-devel \
    json-c-devel \
    pkgconfig
```

## Build from Source

### Step 1: Navigate to Project
```bash
cd <PROJECT_ROOT_DIR>
```

### Step 2: Clean Previous Build
```bash
make clean
```

### Step 3: Build
```bash
make
```

This produces:
- `stickers-editor` (39KB)
- `stickers-render` (23KB)

### Step 4: Verify
```bash
ls -lh stickers-*
./stickers-editor --help  # May not show help, but verifies launch
./stickers-render --help  # Same
```

## Makefile Targets

### Build Targets
```bash
make all              # Build both apps (default)
make editor           # Build editor only
make renderer         # Build renderer only
make clean            # Remove binaries
```

### Run Targets
```bash
make run-editor       # Build and run editor
make run-renderer     # Build and run renderer
```

### Examples
```bash
# Full workflow
make clean
make
./stickers-editor

# Or in one command
make run-editor

# Quick rebuild after code changes
make
```

## Verification

### Compilation Check
```bash
make clean && make 2>&1 | grep -E "error|warning"
# Should produce no output (no errors)
```

### Binary Check
```bash
file stickers-editor stickers-render
# Should show: ELF 64-bit LSB executable

ldd stickers-editor
# Should show gtk4, json-c, gtk4-layer-shell dependencies
```

### Runtime Check
```bash
# Terminal 1: Launch renderer
./stickers-render &

# Terminal 2: Launch editor
./stickers-editor &

# Terminal 3: Monitor processes
ps aux | grep stickers
```

## Compiler Flags

### CFLAGS (Compile Flags)
Generated by `pkg-config`:
```bash
pkg-config --cflags gtk4 gtk4-layer-shell-0 json-c
```

Includes paths to:
- GTK4 headers
- layer-shell headers
- json-c headers
- GLib/GObject headers
- Cairo headers

### LIBS (Linker Flags)
Generated by `pkg-config`:
```bash
pkg-config --libs gtk4 gtk4-layer-shell-0 json-c
```

Links against:
- libgtk-4
- libgtk4-layer-shell
- libjson-c
- libgobject-2.0
- libglib-2.0
- libcairo

## Troubleshooting

### Error: `pkg-config: command not found`
**Solution:** Install pkg-config
```bash
# Arch
sudo pacman -S pkgconf

# Ubuntu
sudo apt-get install pkg-config

# Fedora
sudo dnf install pkgconfig
```

### Error: `gtk/gtk.h: No such file or directory`
**Solution:** Install GTK4 development package
```bash
# Arch
sudo pacman -S gtk4

# Ubuntu
sudo apt-get install libgtk-4-dev

# Fedora
sudo dnf install gtk4-devel
```

### Error: `gtk4-layer-shell.h: No such file`
**Solution:** Install gtk4-layer-shell
```bash
# Arch
sudo pacman -S gtk4-layer-shell

# Ubuntu
sudo apt-get install libgtk4-layer-shell0

# Fedora
sudo dnf install gtk4-layer-shell-devel
```

### Error: `json.h: No such file`
**Solution:** Install json-c
```bash
# Arch
sudo pacman -S json-c

# Ubuntu
sudo apt-get install libjson-c-dev

# Fedora
sudo dnf install json-c-devel
```

### Linker Error: `undefined reference to 'gtk_...`
**Cause:** Missing GTK library  
**Solution:**
```bash
# Verify pkg-config finds libraries
pkg-config --libs gtk4
# Should include -lgtk-4

# Rebuild
make clean && make
```

### Build Succeeds but No Binary
**Cause:** Previous build failed, object files corrupt  
**Solution:**
```bash
make clean
make
ls stickers-*
```

### Stickers Don't Appear
**Check:**
```bash
# 1. Verify config file
cat config/stickers.json

# 2. Check asset paths exist
ls assets/
ls assets/Abby.png

# 3. Verify renderer launched
ps aux | grep stickers-render

# 4. Check Wayland session
echo $WAYLAND_DISPLAY
```

## Platform-Specific Notes

### Arch Linux
- Most tested platform
- All dependencies in official repos
- Latest GTK4 versions

### Ubuntu/Debian
- May need older GTK4 versions
- Layer-shell might require additional setup
- Wayland not default; ensure running Wayland session

### Fedora
- Rolling release, similar to Arch
- Slightly different package names

### Wayland Requirement
```bash
# Check if running Wayland
echo $WAYLAND_DISPLAY
# Should output something like "wayland-0"

# Or check session type
echo $XDG_SESSION_TYPE
# Should output "wayland" (not "x11")
```

## Development Build

### Debug Build (With Debugging Symbols)
```bash
# Modify Makefile to add -g flag
CC = gcc
CFLAGS = -g $(shell pkg-config --cflags gtk4 gtk4-layer-shell-0 json-c)
LIBS = $(shell pkg-config --libs gtk4 gtk4-layer-shell-0 json-c)

make clean && make
```

Then debug with:
```bash
gdb ./stickers-editor
```

### Verbose Build
```bash
make clean
make V=1  # If Makefile supports verbose mode

# Or directly
gcc -v src/editor/main.c ... -o stickers-editor
```

### Profile Build
```bash
# Add profiling to Makefile
CFLAGS = -pg $(shell pkg-config --cflags gtk4 gtk4-layer-shell-0 json-c)

make clean && make
./stickers-editor
gprof stickers-editor gmon.out
```

## CI/CD Integration

### GitHub Actions Example
```yaml
name: Build
on: [push]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Install Dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y libgtk-4-dev libgtk4-layer-shell0 libjson-c-dev pkg-config
      - name: Build
        run: make clean && make
      - name: Verify
        run: file stickers-editor stickers-render
```

## Release Build

### Strip Binaries
```bash
make
strip stickers-editor stickers-render
ls -lh stickers-*
# Should be smaller (debug symbols removed)
```

### Package for Distribution
```bash
mkdir -p stickers-release/{bin,assets,config}
cp stickers-editor stickers-render stickers-release/bin/
cp -r assets/* stickers-release/assets/
cp config/stickers.json stickers-release/config/
tar czf stickers-release.tar.gz stickers-release/
```

## Build Customization

### Change Output Directory
```makefile
# In Makefile
BINDIR = /usr/local/bin
editor:
    $(CC) $(EDITOR_SRC) -o $(BINDIR)/stickers-editor $(CFLAGS) $(LIBS)
```

### Add Compiler Optimizations
```makefile
CFLAGS = -O2 $(shell pkg-config --cflags gtk4 gtk4-layer-shell-0 json-c)
```

### Add Warning Flags
```makefile
CFLAGS = -Wall -Wextra -pedantic $(shell pkg-config --cflags gtk4 gtk4-layer-shell-0 json-c)
```
